# 狗狗特工 Android 更新

此公開儲存庫只提供 APK、版本資訊和更新說明，無須登入 GitHub。原始碼與交接包維持私有，不在這裡發布。

## 下載

請至 [Releases](https://github.com/cychang0728/dog-agent-updates/releases) 下載單一 APK，支援 x86_64 與 arm64-v8a。Mac MuMu 尚未實機驗證。

Android.19 起內建每 6 小時檢查新版。下載及安裝分別需要使用者確認；必須先關閉天堂 M 並停止控制。遊戲仍在執行或無法確認已關閉時會阻擋更新，不會自動續傳、靜默安裝或 Root 安裝。Android.18 及更舊版本需先手動安裝一次新版。

每個正式 Release 提供 `update.json`（版本、大小、SHA256、APK 網址與說明）及 `DogAgent-Android.N.apk`。穩定更新入口為 `releases/latest/download/update.json`；測試版不會自動加入穩定更新。

APK 只用於使用者自己的合法測試；請自行評估遊戲服務條款與帳號風險。
